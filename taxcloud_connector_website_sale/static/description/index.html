KEY HIGHLIGHTS

Tax at Checkout

Sales tax is computed when the delivery method changes and on the payment step.

 

Payment Guard

Customers cannot pay without sales tax, even from an old payment page.

 

Silent Address Verification

The verified address is used for tax only; customers see no extra step.

 

Fewer API Calls

Unchanged carts reuse the last result instead of calling TaxCloud on every page.

FREQUENT QUESTIONS

Q
What happens if TaxCloud is down during checkout?
A
Payment is blocked with a message asking the customer to try again in a few minutes. No order is paid without sales tax.
 
Q
Is the customer address modified?
A
No. Verification results are only used for the TaxCloud request.
 
Q
Why do website orders not use TaxCloud?
A
Make sure the TaxCloud fiscal position has Auto-apply enabled for the United States.
