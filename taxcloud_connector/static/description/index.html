TaxCloud Settings

Go to Invoicing > Configuration > Settings > Taxes > TaxCloud. Enter the API key and connection ID, choose the tax template and default TIC, then click Test Connection.

TaxCloud Fiscal Position

Open Automatic Tax Mapping (TaxCloud) in Invoicing > Configuration > Fiscal Positions. "Use TaxCloud API" is ticked; enable Auto-apply for the United States.

Taxability Information Codes

Set the TaxCloud TIC on a product (Accounting tab) or on its product category.

Verify a Customer Address

On a US contact, click Verify next to the address.

Address Comparison

Compare the current address with TaxCloud's suggestion and click Apply Suggestion. The contact is marked Verified.

Exemption Certificate

Enter the TaxCloud exemption certificate ID on the customer (Sales & Purchase tab, Fiscal Information).

Invoice with TaxCloud Taxes

A customer invoice using the TaxCloud fiscal position. Taxes are computed with Compute Taxes and again on confirmation.

Reported to TaxCloud

After posting, the invoice is reported. Other Info shows the TaxCloud status, order ID and report date.

Reporting Error and Retry

If TaxCloud rejects a report, a banner shows the reason with a Retry button.

Pending and Failed Reports

Use the TaxCloud Errors and TaxCloud Pending filters in the invoice list.

Refund a TaxCloud Invoice

Reverse a reported invoice. The credit note is reported as a full or partial TaxCloud refund.

TaxCloud API Logs

Accounting > Configuration > TaxCloud Logs lists every failed call (and every call with debug logging on).

FREQUENT QUESTIONS

Q
Does this module work with Odoo Community?
A
Yes. The connector and its Sales, eCommerce and Point of Sale bridges run on Odoo 20 Community and Enterprise.
 
Q
Which TaxCloud API does it use?
A
The TaxCloud API v3 (api.v3.taxcloud.com), authenticated with an API key and a connection ID. Use a test connection while setting up.
 
Q
When are invoices reported to TaxCloud?
A
When they are posted. A background job converts the TaxCloud cart into a completed order and retries temporary errors up to 5 times.
 
Q
Can I reset a reported invoice to draft?
A
Yes, as long as TaxCloud still allows voiding the order (until the 10th of the following month) and no refund was reported. Otherwise use a credit note.
 
Q
How are partial refunds handled?
A
A credit note created by reversing an invoice is reported as a refund of the returned items and quantities.
 
Q
Is the customer address changed during tax calculation?
A
Never. When verification is enabled, the verified address is only used in the request sent to TaxCloud.
 
Q
What if TaxCloud is unreachable?
A
Posting is blocked with a clear message, so no invoice is posted without sales tax. Reporting is retried automatically.
